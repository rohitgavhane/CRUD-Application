# CRUD Application 🛠️

A sleek and modern CRUD (Create, Read, Update, Delete) web app built with **React**, **Bootstrap**, **Axios**, and **Node.js REST API**.

---

## 🚀 Features

- ➕ Add new students  
- 📋 View all students  
- ✏️ Update student data  
- ❌ Delete students  
- 🎨 Smooth and responsive UI using Bootstrap + Framer Motion

---

## 🧰 Tech Stack

- **Frontend:** React, Bootstrap, Framer Motion  
- **Backend:** Node.js, Express.js  
- **HTTP Client:** Axios  
- **Version Control:** Git & GitHub

## 📦 Getting Started

Follow these steps to run the app locally:

```bash
# Clone the repository
git clone https://github.com/rohitgavhane/CRUD-Application.git

# Navigate into the project directory
cd CRUD-Application

# Install dependencies
npm install

# Start the development server
npm start
